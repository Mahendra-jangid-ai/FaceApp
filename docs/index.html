What it does

Built for the field, not the lab

Every capability runs on-device so a supervisor at a remote highway stretch needs no signal to verify a worker.

🧠

Custom Face Recognition

Self-trained MobileFaceNet + ArcFace on 490K faces / 10,572 identities. 128-D embeddings, 99.28% LFW verification accuracy.

👁️

Active Liveness

Three randomized challenges — blink, smile, head-turn — with real-time progress, defeating photo and video replay attacks.

🛡️

Anti-Spoofing

Laplacian-variance texture analysis flags printed photos and phone screens before a match is ever attempted.

🔐

BioHash Privacy

ISO/IEC 24745 cancellable templates. The raw face vector is never stored — templates can be revoked and re-issued.

📍

GPS Geofencing

Check-in / check-out is validated against site boundaries, so attendance is tied to actually being on the worksite.

🦺

PPE Compliance

Helmet and hi-vis vest detection gates site entry, turning attendance into a safety checkpoint.

📡

Offline-First Sync

All operations work with zero connectivity; records sync to NHAI Datalake 3.0 with exponential-backoff retry when back online.

🆔

Aadhaar Linkage

Optional Aadhaar capture with Verhoeff checksum validation and masked display for identity assurance.

📊

Live Analytics

On-device dashboard: liveness pass rate, match confidence, spoof blocks, geofence compliance and 7-day trends.

Under the hood

Engineering that holds up in production

On-Device Pipeline

  • VisionCamera v5 capture (front/back)
  • ML Kit face detection + classification
  • Custom MobileFaceNet 128-D embeddings (ONNX)
  • Eye-aligned geometric fallback for universal support
  • Cosine matching with adaptive thresholds

Security & Privacy

  • BioHash ISO/IEC 24745 cancellable templates
  • AES-256-GCM encryption at rest
  • Liveness + Laplacian anti-spoof scoring
  • 3-attempt lockout with cooldown
  • GDPR-style data retention & purge

Platform

  • React Native 0.85 · New Architecture · Hermes
  • Native Kotlin face-processor module
  • Encrypted local store, offline-first
  • Background sync to NHAI Datalake 3.0
  • Standalone APK — no Metro / no server

Field Features

  • GPS geofencing for site-bound attendance
  • PPE (helmet / vest) compliance gate
  • Aadhaar Verhoeff validation
  • Hindi / English voice prompts
  • Live analytics & 7-day trends
